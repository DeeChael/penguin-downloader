# 提供者开发指南

## 概述

提供者（Provider）实现 `MusicProvider` trait，用于访问特定的音乐源。

### 3. search_songs() - 搜索歌曲

```rust
async fn search_songs(
    &self,
    keyword: &str,              // 搜索关键词
    pagination: Pagination,     // 分页参数
    credential: Option<&str>,   // 认证凭据（可选）
) -> penguin_downloader::Result<Option<SearchResult>> {
    // 计算分页偏移
    let offset = pagination.offset();
    let limit = pagination.per_page;
    
    // 调用API
    let url = format!(
        "https://api.example.com/search?q={}&limit={}&offset={}",
        urlencoding::encode(keyword),
        limit,
        offset
    );
    
    let response = self.client
        .get(&url)
        .send()
        .await?;
    
    // 解析响应
    let data: serde_json::Value = response.json().await?;
    
    // 转换为SongInfo列表
    let songs: Vec<SongInfo> = data["songs"]
        .as_array()
        .unwrap_or(&vec![])
        .iter()
        .map(|s| SongInfo {
            id: s["id"].as_str().unwrap_or("").to_string(),
            title: s["name"].as_str().unwrap_or("未知").to_string(),
            artist: s["artist"].as_str().unwrap_or("未知艺人").to_string(),
            album: s["album"].as_str().map(String::from),
            ..Default::default()
        })
        .collect();
    
    Ok(Some(SearchResult::success(songs)))
}
```

### 4. get_song_url() - 获取下载链接

```rust
async fn get_song_url(
    &self,
    song: &SongInfo,            // 歌曲信息
    quality: i32,               // 音质等级
    credential: Option<&str>,   // 认证凭据
) -> penguin_downloader::Result<Option<SongUrlResult>> {
    // 将音质映射到服务特定参数
    let quality_param = match quality {
        3 => "lossless",
        2 => "high",
        _ => "standard",
    };
    
    // 请求URL
    let url = format!("https://api.example.com/song/{}/url", song.id);
    
    let response = self.client
        .get(&url)
        .query(&[("quality", quality_param)])
        .send()
        .await?;
    
    let data: serde_json::Value = response.json().await?;
    
    // 解析结果
    if let Some(url) = data["url"].as_str() {
        Ok(Some(SongUrlResult::success(url, quality_param)))
    } else {
        Ok(None)
    }
}
```

    ]

// 二维码登录
async fn start_qr_login(
    &self,
    callback: &dyn QrLoginCallback,
    timeout: std::time::Duration,
) -> penguin_downloader::Result<String> {
    // 1. 获取二维码
    let qr_data = self.get_qr_code().await?;
    
    // 2. 显示二维码
    callback.on_qr(
        &QrLoginData::Image(qr_data.image),
        &qr_data.key
    ).await;
    
    // 3. 轮询登录状态
    let start = std::time::Instant::now();
    loop {
        if start.elapsed() > timeout {
            return Err(penguin_downloader::Error::LoginTimeout);
        }
        
        match self.check_qr_status(&qr_data.key).await? {
            LoginStatus::Success => {
                let credential = self.get_credential().await?;
                return Ok(credential);
            }
            LoginStatus::Failed(msg) => {
                return Err(penguin_downloader::Error::LoginFailed(msg));
            }
            _ => {
                tokio::time::sleep(std::time::Duration::from_secs(2)).await;
            }
        }
    }
}

// 刷新认证
async fn refresh_and_validate(
    &self,
    credential: &str,
    timeout: std::time::Duration,
) -> penguin_downloader::Result<String> {
    // 刷新token/session
    Ok(credential.to_string())
}

## 完整示例

```rust
use async_trait::async_trait;
use penguin_downloader::{
    model::*,
    provider::{MusicProvider, ProviderInfo, Pagination, LoginMethod},
};
use std::collections::HashMap;
use std::sync::Arc;

pub struct MyProvider {
    client: reqwest::Client,
    base_url: String,
}

impl MyProvider {
    pub fn new() -> Self {
        Self {
            client: reqwest::Client::new(),
            base_url: "https://api.music.example.com".to_string(),
        }
    }
}

#[async_trait]
impl MusicProvider for MyProvider {
    fn info(&self) -> ProviderInfo {
        ProviderInfo::new("my_provider", "my_plugin", "我的音乐源")
    }
    
    fn quality_levels(&self) -> &HashMap<i32, String> {
        use std::sync::OnceLock;
        static LEVELS: OnceLock<HashMap<i32, String>> = OnceLock::new();
        LEVELS.get_or_init(|| {
            let mut m = HashMap::new();
            m.insert(1, "128kbps".to_string());
            m.insert(2, "320kbps".to_string());
            m.insert(3, "无损音质".to_string());
            m
        })
    }
    
    async fn search_songs(
        &self,
        keyword: &str,
        pagination: Pagination,
        _credential: Option<&str>,
    ) -> penguin_downloader::Result<Option<SearchResult>> {
        let url = format!("{}/search", self.base_url);
        
        let response = self.client
            .get(&url)
            .query(&[
                ("q", keyword),
                ("limit", &pagination.per_page.to_string()),
                ("offset", &pagination.offset().to_string()),
            ])
            .send()
            .await?;
        
        let data: serde_json::Value = response.json().await?;
        
        let songs: Vec<SongInfo> = data["songs"]
            .as_array()
            .unwrap_or(&vec![])
            .iter()
            .filter_map(|s| {
                Some(SongInfo {
                    id: s["id"].as_str()?.to_string(),
                    title: s["name"].as_str()?.to_string(),
                    artist: s["artist"].as_str()?.to_string(),
                    album: s["album"].as_str().map(String::from),
                    cover: s["cover"].as_str().map(String::from),
                    ..Default::default()
                })
            })
            .collect();
        
        Ok(Some(SearchResult::success(songs)))
    }
    
    async fn get_song_url(
        &self,
        song: &SongInfo,
        quality: i32,
        _credential: Option<&str>,
    ) -> penguin_downloader::Result<Option<SongUrlResult>> {
        let url = format!("{}/song/{}/url", self.base_url, song.id);
        
        let quality_str = match quality {
            3 => "lossless",
            2 => "high",
            _ => "standard",
        };
        
        let response = self.client
            .get(&url)
            .query(&[("quality", quality_str)])
            .send()
            .await?;
        
        let data: serde_json::Value = response.json().await?;
        
        if let Some(url) = data["url"].as_str() {
            Ok(Some(SongUrlResult::success(url, quality_str)))
        } else {
            Ok(None)
        }
    }
    
    fn supported_login_methods(&self) -> Vec<LoginMethod> {
        vec![LoginMethod::None]
    }
    
    fn download_referer(&self) -> String {
        self.base_url.clone()
    }
}
```

## 最佳实践

1. **错误处理**: 返回 `Ok(None)` 表示"未找到"，使用 `Err` 表示失败
2. **Rate Limiting**: 实现速率限制以避免API限制
3. **Caching**: 缓存频繁访问的数据
4. **Timeouts**: 始终为网络请求使用超时
5. **Validation**: 处理前验证所有输入
6. **Logging**: 使用结构化日志进行调试
7. **Documentation**: 记录任何特定于提供者的行为
