# 插件开发指南

## 概述

Penguin Downloader 使用插件系统来扩展功能。插件可以包含：
- **提供者 (Provider)**: 音乐源实现
- **标签器 (Tagger)**: 元数据检索服务

## 创建插件项目

### 1. 创建新项目

```bash
cargo new --lib my-plugin
cd my-plugin
```

### 2. 配置 Cargo.toml

```toml
[package]
name = "my-plugin"
version = "0.1.0"
edition = "2021"

[lib]
name = "my_plugin"
crate-type = ["cdylib"]  # 必须编译为动态库

[dependencies]
penguin-downloader = "1.0"
tokio = { version = "1", features = ["rt-multi-thread", "macros"] }
async-trait = "0.1"
anyhow = "1"
tracing = "0.1"
```

### 3. 编写插件代码

在 `src/lib.rs` 中：

```rust
use std::sync::Arc;
use penguin_downloader::{
    plugin::{PenguinPlugin, PluginInfo},
    provider::{MusicProvider, ProviderInfo},
    tagger::{Tagger, TaggerInfo},
};

// 定义插件
struct MyPlugin;

impl PenguinPlugin for MyPlugin {
    // 返回插件信息
    fn info(&self) -> PluginInfo {
        PluginInfo::new(
            "my_plugin",                    // 插件ID
            "我的插件",                      // 插件名称
            "1.0.0",                        // 版本
            "这是一个示例插件",               // 描述
        )
    }
    
    // 注册提供者
    fn register_providers(&self,
    ) -> Vec<(String, Arc<dyn MusicProvider>)> {
        vec![
            ("my_provider".to_string(), Arc::new(MyProvider::new())),
        ]
    }
    
    // 注册标签器（可选）
    fn register_taggers(&self,
    ) -> Vec<(String, Arc<dyn Tagger>)> {
        vec![
            ("my_tagger".to_string(), Arc::new(MyTagger::new())),
        ]
    }
}

// 导出插件创建函数
#[no_mangle]
pub unsafe extern "C" fn penguin_plugin_create() -> *mut dyn PenguinPlugin {
    let plugin: Box<dyn PenguinPlugin> = Box::new(MyPlugin);
    Box::into_raw(plugin)
}
```

## 编译插件

### 开发构建

```bash
cargo build
```

### 发布构建（推荐）

```bash
cargo build --release
```

编译后的插件位于：
- Windows: `target/release/my_plugin.dll`
- Linux: `target/release/libmy_plugin.so`
- macOS: `target/release/libmy_plugin.dylib`

## 测试插件

### 1. 创建测试项目

```bash
cargo new test-plugin
cd test-plugin
```

### 2. 编写测试代码

```rust
use penguin_downloader::PenguinCore;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let core = PenguinCore::new();
    
    // 加载插件
    core.load_plugin_from_file("../my-plugin/target/release/my_plugin.dll")?;
    
    // 列出所有提供者
    let providers = core.list_provider_names();
    println!("可用提供者: {:?}", providers);
    
    // 测试提供者
    if let Some(provider) = core.get_provider("my_provider") {
        println!("提供者名称: {}", provider.name());
        
        // 测试搜索
        let result = provider.search_songs(
            "测试",
            penguin_downloader::Pagination::default_search(),
            None,
        ).await?;
        
        if let Some(search_result) = result {
            println!("找到 {} 首歌曲", search_result.songs.len());
        }
    }
    
    Ok(())
}
```

### 3. 运行测试

```bash
cargo run
```

## 最佳实践

### 1. 错误处理

```rust
async fn fetch_data(&self,
) -> penguin_downloader::Result<SomeData> {
    match self.client.get("...").send().await {
        Ok(response) => {
            if response.status().is_success() {
                Ok(response.json().await?)
            } else {
                Err(penguin_downloader::Error::Provider(
                    format!("API错误: {}", response.status())
                ))
            }
        }
        Err(e) => {
            tracing::error!("请求失败: {}", e);
            Err(e.into())
        }
    }
}
```

### 2. 日志记录

```rust
use tracing::{info, debug, warn, error};

impl MusicProvider for MyProvider {
    async fn search_songs(&self,
        keyword: &str,
        pagination: Pagination,
        _credential: Option<&str>,
    ) -> Result<Option<SearchResult>> {
        info!(keyword = %keyword, "开始搜索");
        
        debug!(offset = pagination.offset(), "计算偏移量");
        
        let result = self.do_search(keyword, pagination).await?;
        
        info!(count = result.songs.len(), "搜索完成");
        
        Ok(Some(result))
    }
}
```

### 3. 资源管理

```rust
use std::sync::Arc;
use parking_lot::RwLock;

pub struct MyProvider {
    client: reqwest::Client,
    cache: Arc<RwLock<HashMap<String, CachedData>>>,
}

impl MyProvider {
    pub fn new() -> Self {
        Self {
            client: reqwest::Client::new(),
            cache: Arc::new(RwLock::new(HashMap::new())),
        }
    }
    
    async fn get_cached(&self,
        key: &str,
    ) -> Option<CachedData> {
        self.cache.read().get(key).cloned()
    }
}
```

### 4. 版本兼容性

遵循语义化版本控制：
- **MAJOR**: 破坏性API变更
- **MINOR**: 新功能，向后兼容
- **PATCH**: Bug修复

在 `Cargo.toml` 中指定兼容的核心版本：

```toml
[dependencies]
penguin-downloader = "~1.0"  # 兼容1.0.x
```

## 调试技巧

### 启用详细日志

```rust
use tracing_subscriber;

tracing_subscriber::fmt()
    .with_env_filter("debug")
    .init();
```

### 常见问题

1. **符号未找到**: 确保 `penguin_plugin_create` 函数已导出
2. **ABI不匹配**: 重新编译插件以匹配核心版本
3. **加载失败**: 检查文件权限和路径
4. **运行时崩溃**: 避免使用 unsafe 代码，正确处理错误
