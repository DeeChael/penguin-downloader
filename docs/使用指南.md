# Penguin Downloader 使用文档

## 简介

Penguin Downloader 是一个模块化的音乐下载器核心库，支持通过插件动态加载不同的音乐源和元数据服务。

## 快速开始

### 添加依赖

在 `Cargo.toml` 中添加：

```toml
[dependencies]
penguin-downloader = "1.0"
tokio = { version = "1", features = ["rt-multi-thread", "macros"] }
```

### 基本使用

```rust
use penguin_downloader::{PenguinCore, DownloadOptions};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // 创建核心实例
    let core = PenguinCore::new();
    
    // 加载插件
    core.load_plugins_from_dir("./plugins")?;
    
    // 获取提供者
    let provider = core.get_provider("provider_id")
        .expect("提供者未找到");
    
    // 创建下载器
    let downloader = core.get_downloader(provider, None);
    
    // 搜索歌曲
    let songs = provider.search_songs("关键词", Pagination::default_search(), None).await?;
    
    if let Some(result) = songs {
        for song in result.songs {
            // 下载歌曲
            let options = DownloadOptions::default();
            downloader.download_song(&song, &options, None).await?;
        }
    }
    
    Ok(())
}
```

## 核心概念

### 提供者 (Provider)

提供者是实现 `MusicProvider` trait 的插件，负责：
- 搜索歌曲、专辑和歌单
- 获取歌曲下载链接
- 管理音乐服务的认证

### 标签器 (Tagger)

标签器是实现 `Tagger` trait 的插件，提供：
- 从外部数据库检索元数据
- 获取专辑封面
- 补全音轨信息

### 核心 (Core)

`PenguinCore` 是主要入口点，负责：
- 插件管理
- 提供者访问
- 下载协调

## API 参考

### PenguinCore

```rust
// 创建实例
let core = PenguinCore::new();

// 从目录加载插件
core.load_plugins_from_dir("./plugins")?;

// 从文件加载插件
core.load_plugin_from_file("./plugins/my_plugin.dll")?;

// 获取提供者
let provider = core.get_provider("provider_id");

// 列出所有提供者
let providers = core.list_provider_names();

// 创建下载器
let downloader = core.get_downloader(provider, None);
```

### 搜索

```rust
// 搜索歌曲
let result = provider.search_songs(
    "关键词",
    Pagination::default_search(),
    None,  // 可选：认证凭据
).await?;

// 搜索专辑
let albums = provider.search_albums(
    "专辑名",
    Pagination::default_search(),
    None,
).await?;
```

### 下载

```rust
// 创建下载选项
let options = DownloadOptions::new()
    .with_quality(2);  // 音质等级

// 下载歌曲
downloader.download_song(&song_info, &options, None).await?;

// 批量下载
let songs = vec![song1, song2, song3];
downloader.download_songs(&songs, &options, None).await?;
```

### 元数据获取

```rust
// 获取标签器
let tagger = penguin_downloader::get_tagger("tagger_id")
    .expect("标签器未找到");

// 获取元数据
if let Some(metadata) = tagger.fetch_metadata(&song_info).await {
    println!("标题: {}", metadata.title);
    println!("艺术家: {:?}", metadata.artist);
    println!("专辑: {:?}", metadata.album);
}
```

## 配置选项

### DownloadOptions

```rust
use penguin_downloader::model::LyricType;

let options = DownloadOptions::new()
    .with_quality(2)                           // 音质 (0=自动, 数字越大越好)
    .with_format("mp3")                        // 输出格式
    .with_lyric_type(LyricType::Original)      // 歌词类型
    .with_lyric_translation(true)              // 包含翻译
    .with_lyric_romanization(false)            // 包含罗马音
    .with_force(false);                        // 强制重新下载
```

### Pagination

```rust
// 默认搜索分页 (每页10条)
let pagination = Pagination::default_search();

// 默认列表分页 (每页100条)
let pagination = Pagination::default_list();

// 自定义分页
let pagination = Pagination::new(50, 2);  // 每页50条，第2页
```

## 错误处理

```rust
match provider.search_songs("keyword", Pagination::default_search(), None).await {
    Ok(Some(result)) => {
        // 处理搜索结果
    }
    Ok(None) => {
        println!("未找到结果");
    }
    Err(e) => {
        eprintln!("搜索失败: {}", e);
    }
}
```

## 日志

启用日志输出：

```rust
use tracing_subscriber;

tracing_subscriber::fmt()
    .with_env_filter("info")
    .init();
```

日志级别：
- `error`: 错误信息
- `warn`: 警告信息
- `info`: 一般信息
- `debug`: 调试信息
- `trace`: 详细跟踪

## 示例项目

### 简单的命令行下载器

```rust
use penguin_downloader::{PenguinCore, DownloadOptions, Pagination};
use std::sync::Arc;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // 初始化日志
    tracing_subscriber::fmt::init();
    
    // 创建核心
    let core = PenguinCore::new();
    
    // 加载插件
    core.load_plugins_from_dir("./plugins")?;
    
    // 获取第一个可用的提供者
    let providers = core.list_provider_names();
    if providers.is_empty() {
        println!("没有可用的提供者插件");
        return Ok(());
    }
    
    let provider = core.get_provider(&providers[0])
        .expect("获取提供者失败");
    
    // 搜索歌曲
    println!("搜索中...");
    let result = provider.search_songs(
        "搜索关键词",
        Pagination::default_search(),
        None,
    ).await?;
    
    if let Some(search_result) = result {
        println!("找到 {} 首歌曲", search_result.songs.len());
        
        // 下载第一首
        if let Some(song) = search_result.songs.first() {
            println!("正在下载: {}", song.title);
            
            let downloader = core.get_downloader(provider, None);
            let options = DownloadOptions::default();
            
            downloader.download_song(song, &options, None).await?;
            println!("下载完成!");
        }
    }
    
    Ok(())
}
```
