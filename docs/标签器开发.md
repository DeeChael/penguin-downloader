# 标签器开发指南

## 概述

标签器（Tagger）实现 `Tagger` trait，用于从外部服务检索歌曲的元数据信息。

## 基本结构

```rust
use async_trait::async_trait;
use penguin_downloader::{
    model::{MetadataInfo, SongInfo},
    tagger::{Tagger, TaggerInfo},
};

pub struct ExampleTagger {
    client: reqwest::Client,
}

impl ExampleTagger {
    pub fn new() -> Self {
        Self {
            client: reqwest::Client::new(),
        }
    }
}

#[async_trait]
impl Tagger for ExampleTagger {
    fn info(&self) -> TaggerInfo {
        TaggerInfo::new(
            "example_tagger",
            "my_plugin",
            "示例标签器",
        )
    }
    
    async fn fetch_metadata(
        &self,
        song_info: &SongInfo,
    ) -> Option<MetadataInfo> {
        // 实现元数据获取
        None
    }
}
```

## 必需实现的方法

### 1. info() - 标签器信息

### 2. fetch_metadata() - 获取元数据

```rust
async fn fetch_metadata(
    &self,
    song_info: &SongInfo,   // 用于匹配的歌曲信息
) -> Option<MetadataInfo> {
    // 1. 使用歌曲信息搜索外部数据库
    let query = format!("{} {}", song_info.title, song_info.artist);
    
    // 2. 调用外部API
    let response = self.client
        .get("https://api.metadata.example.com/search")
        .query(&[("q", &query)])
        .send()
        .await
        .ok()?;
    
    // 3. 解析响应
    let data: serde_json::Value = response.json().await.ok()?;
    
    // 4. 找到最佳匹配
    let best_match = data["results"]
        .as_array()?
        .iter()
        .find(|r| self.is_good_match(r, song_info))?;
    
    // 5. 构建MetadataInfo
    Some(MetadataInfo::new(
        best_match["title"].as_str()?.to_string()
    )
    .with_artist(best_match["artist"].as_str()?)
    .with_album(best_match["album"].as_str()?)
    .with_cover(best_match["cover_url"].as_str()?)
    .with_publish_date(best_match["date"].as_str()?)
    .with_track_number(best_match["track"].as_i64()? as i32)
    .with_disc_number(best_match["disc"].as_i64()? as i32))
}
```

## MetadataInfo 结构

```rust
pub struct MetadataInfo {
    pub title: String,              // 标题（必需）
    pub subtitle: Option<String>,   // 副标题/版本
    pub artist: Option<String>,    // 艺术家

    pub disc_number: Option<i32>,  // 碟片号
```

## 完整示例

### 基础标签器

```rust
use async_trait::async_trait;
use penguin_downloader::{
    model::{MetadataInfo, SongInfo},
    tagger::{Tagger, TaggerInfo},
};
use std::collections::HashMap;

pub struct BasicTagger {
    client: reqwest::Client,
    api_key: String,
}

impl BasicTagger {
    pub fn new(api_key: String) -> Self {
        Self {
            client: reqwest::Client::new(),
            api_key,
        }
    }
    
    // 计算匹配度
    fn calculate_match_score(
        &self,
        result: &serde_json::Value,
        song: &SongInfo,
    ) -> f64 {
        let mut score = 0.0;
        
        // 标题匹配
        if let Some(title) = result["title"].as_str() {
            if title.to_lowercase() == song.title.to_lowercase() {
                score += 0.5;
            } else if title.to_lowercase().contains(&song.title.to_lowercase()) {
                score += 0.3;
            }
        }
        
        // 艺术家匹配
        if let Some(artist) = result["artist"].as_str() {
            if artist.to_lowercase() == song.artist.to_lowercase() {
                score += 0.5;
            }
        }
        
        score
    }
}

#[async_trait]
impl Tagger for BasicTagger {
    fn info(&self) -> TaggerInfo {
        TaggerInfo::new("basic_tagger", "my_plugin", "基础标签器")
    }
    
    async fn fetch_metadata(
        &self,
        song_info: &SongInfo,
    ) -> Option<MetadataInfo> {
        // 构建搜索查询
        let query = format!("{} {}", song_info.title, song_info.artist);
        
        // 调用API
        let response = self.client
            .get("https://api.metadata.example.com/")
            .query(&[
                ("search", query.as_str()),
                ("limit", "10"),
            ])
            .header("User-Agent", "PenguinDownloader/1.0")
            .send()
            .await
            .ok()?;
        
        let data: serde_json::Value = response.json().await.ok()?;
        
        // 找到最佳匹配
        let recordings = data["recordings"].as_array()?;
        let best_match = recordings
            .iter()
            .max_by(|a, b| {
                let score_a = self.calculate_match_score(a, song_info);
                let score_b = self.calculate_match_score(b, song_info);
                score_a.partial_cmp(&score_b).unwrap()
            })?;
        
        // 检查匹配度是否足够高
        if self.calculate_match_score(best_match, song_info) < 0.5 {
            return None;
        }
        
        // 提取信息
        let title = best_match["title"].as_str()?.to_string();
        let artist = best_match["artist-credit"]
            .as_array()?
            .first()
            .and_then(|a| a["name"].as_str())
            .map(String::from);
        
        let album = best_match["releases"]
            .as_array()?
            .first()
            .and_then(|r| r["title"].as_str())
            .map(String::from);
        
        let track_number = best_match["releases"]
            .as_array()?
            .first()
            .and_then(|r| r["track-number"].as_str())
            .and_then(|n| n.parse::<i32>().ok());
        
        // 构建MetadataInfo
        let mut metadata = MetadataInfo::new(title);
        
        if let Some(artist) = artist {
            metadata = metadata.with_artist(artist);
        }
        if let Some(album) = album {
            metadata = metadata.with_album(album);
        }
        if let Some(track) = track_number {
            metadata = metadata.with_track_number(track);
        }
        
        Some(metadata)
    }
}
```

### 封面获取标签器

```rust
use async_trait::async_trait;
use penguin_downloader::{
    model::{MetadataInfo, SongInfo},
    tagger::{Tagger, TaggerInfo},
};

pub struct CoverArtTagger {
    client: reqwest::Client,
}

impl CoverArtTagger {
    pub fn new() -> Self {
        Self {
            client: reqwest::Client::new(),
        }
    }
    
    // 搜索封面
    async fn search_cover(
        &self,
        album: &str,
        artist: &str,
    ) -> Option<String> {
        let query = format!("{} {}", album, artist);
        
        let response = self.client
            .get("https://metadata.example.com/release/")
            .query(&[("query", query.as_str())])
            .send()
            .await
            .ok()?;
        
        let data: serde_json::Value = response.json().await.ok()?;
        
        // 提取封面URL
        data["releases"]
            .as_array()?
            .first()
            .and_then(|r| r["id"].as_str())
            .map(|id| format!("https://metadata.example.com/release/{}", id))
    }
}

#[async_trait]
impl Tagger for CoverArtTagger {
    fn info(&self) -> TaggerInfo {
        TaggerInfo::new("cover_tagger", "my_plugin", "封面标签器")
    }
    
    async fn fetch_metadata(
        &self,
        song_info: &SongInfo,
    ) -> Option<MetadataInfo> {
        // 需要专辑信息才能搜索封面
        let album = song_info.album.as_ref()?;
        
        // 搜索封面
        let cover_url = self.search_cover(album, &song_info.artist).await?;
        
        // 构建MetadataInfo，主要提供封面
        Some(MetadataInfo::new(song_info.title.clone())
            .with_artist(&song_info.artist)
            .with_album(album)
            .with_cover(cover_url))
    }
}
```

### 组合标签器

```rust
use async_trait::async_trait;
use penguin_downloader::{
    model::{MetadataInfo, SongInfo},
    tagger::{Tagger, TaggerInfo},
};
use std::sync::Arc;

// 组合多个标签器的结果
pub struct CompositeTagger {
    taggers: Vec<Arc<dyn Tagger>>,
}

impl CompositeTagger {
    pub fn new(taggers: Vec<Arc<dyn Tagger>>) -> Self {
        Self { taggers }
    }
    
    // 合并多个MetadataInfo
    fn merge_metadata(&self,
        base: SongInfo,
        metadatas: Vec<MetadataInfo>,
    ) -> MetadataInfo {
        let mut result = MetadataInfo::new(base.title);
        
        // 优先使用第一个标签器的信息
        if let Some(first) = metadatas.first() {
            result = MetadataInfo::new(first.title.clone());
            
            if let Some(ref subtitle) = first.subtitle {
                result = result.with_subtitle(subtitle.clone());
            }
            if let Some(ref artist) = first.artist {
                result = result.with_artist(artist.clone());
            }
            if let Some(ref album) = first.album {
                result = result.with_album(album.clone());
            }
        }
        
        // 从其他标签器补充信息
        for metadata in &metadatas {
            // 如果之前的标签器没有提供封面，使用后面的
            if result.cover.is_none() && metadata.cover.is_some() {
                result.cover = metadata.cover.clone();
            }
            
            // 补充音轨号、碟片号
            if result.track_number.is_none() && metadata.track_number.is_some() {
                result.track_number = metadata.track_number;
            }
            if result.disc_number.is_none() && metadata.disc_number.is_some() {
                result.disc_number = metadata.disc_number;
            }
        }
        
        result
    }
}

#[async_trait]
impl Tagger for CompositeTagger {
    fn info(&self) -> TaggerInfo {
        TaggerInfo::new("composite_tagger", "my_plugin", "组合标签器")
    }
    
    async fn fetch_metadata(
        &self,
        song_info: &SongInfo,
    ) -> Option<MetadataInfo> {
        // 从所有标签器收集元数据
        let mut metadatas = Vec::new();
        
        for tagger in &self.taggers {
            if let Some(metadata) = tagger.fetch_metadata(song_info).await {
                metadatas.push(metadata);
            }
        }
        
        if metadatas.is_empty() {
            None
        } else {
            Some(self.merge_metadata(song_info.clone(), metadatas))
        }
    }
}
```

## 最佳实践

1. **匹配算法**: 使用模糊匹配或相似度算法提高匹配率
2. **缓存**: 缓存频繁请求的结果
3. **错误处理**: 网络错误时不应中断，返回 None 即可
4. **尊重API限制**: 添加适当的延迟和重试机制
5. **日志记录**: 记录搜索和匹配过程便于调试
